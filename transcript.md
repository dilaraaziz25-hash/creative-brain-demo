# Digital Transformation Strategy — Q3 Planning Session

Participants: Sarah (Project Lead), Marcus (IT Director), Priya (Finance), Tom (Operations), Lisa (HR)

Sarah: Right, thanks everyone for joining. Today we need to lock down our digital transformation roadmap for Q3. We've been talking about this for six months, so let's make some actual decisions. I think we just go with what we discussed last time — migrate everything to the cloud, roll out the new ERP system, and retire the legacy infrastructure.

Marcus: Agreed. We've done this kind of migration before. The playbook is the same — lift and shift, test in staging, push to prod.

Tom: Yeah that worked fine for the warehouse system. I say we just replicate that approach.

Priya: The budget looks manageable if we stick to the same vendor we used last time. I don't see a reason to shop around.

Sarah: Great, so we're aligned. Cloud migration, same vendor, same approach. I'll draft the proposal —

Marcus: Actually, before we lock that in — should we think about whether lift-and-shift is really the right call here? The ERP migration is a lot more complex than the warehouse system.

Sarah: Fair point. But we're under pressure to show progress. Let's not overthink it.

Tom: Agreed, let's just move.

Lisa: I do want to flag something — we haven't talked at all about the people side of this. We're rolling out a completely new ERP to 400 staff and nobody's mentioned training or change management.

Sarah: We'll handle that in the implementation phase.

Priya: I'll be honest — I'm a bit worried about cost overruns. ERP migrations almost always go over budget. But I don't want to slow things down.

Marcus: Let's just set a 20% contingency and move on.

Sarah: I think 20% is pretty standard for this kind of project isn't it? That's what everyone does.

Sarah: Good. So — cloud migration, same vendor, lift-and-shift, 20% contingency. Are we done?

Tom: I think so.

Marcus: Yeah.

Lisa: I still think we need a proper change management plan but... okay.
