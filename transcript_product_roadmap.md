# Product Roadmap Prioritisation — Q3 Planning Session
Participants: James (CPO), Nina (Engineering Lead), Raj (Product Manager), Clara (UX Lead), Ben (Sales Director)

James: Right, let's lock down the Q3 roadmap. We've got three big items competing for bandwidth — the mobile app redesign, the API integrations, and the analytics dashboard. I think we lead with the mobile redesign. It's been on the list for two years and customers keep asking for it.

Nina: Engineering is aligned on mobile. We know the codebase well, the team is familiar with it. It's lower risk than the API work.

Raj: Agreed. Mobile has the most Jira tickets from customers. That's a clear signal.

Clara: From UX perspective, mobile is definitely overdue. I've got six months of research ready to go.

James: Perfect, so mobile first. We can push API integrations to Q4 and the dashboard to next year.

Ben: Hold on — I need to flag something. Three of our top enterprise prospects specifically asked about the API integrations last week. Two of them said it's a blocker for signing.

James: Sales always says everything is urgent, Ben. We can't let individual deals drive the roadmap.

Ben: These aren't small deals. We're talking about £2M combined. But if the team thinks mobile is the priority...

Raj: The data supports mobile. It's not just one or two customers.

Nina: And we'd be context-switching the team if we pivot to APIs now. That's expensive.

Clara: Mobile research is already done. Starting APIs from scratch would set us back months.

James: So we're agreed — mobile first, APIs in Q4. Ben, you can tell prospects Q4 for the API work.

Ben: I mean... okay. I just want it on record that we might lose those deals.

James: Noted. Let's move on to resourcing.

Nina: I think we should also confirm we're not touching the analytics dashboard until next year. It's the most complex piece.

Raj: Agreed, dashboard can wait. Customers aren't screaming for it.

James: Good. Mobile, then APIs, then dashboard. That's the roadmap.

Ben: What about the performance issues we've been seeing? Three enterprise clients flagged slow load times last month.

James: That's an engineering maintenance thing, not a roadmap item.

Nina: We can handle that in sprints alongside the mobile work.

Ben: Okay. I just hope we're not building a beautiful new mobile app that runs slowly.

James: We'll handle it. Are we done?

Raj: I think so.

Clara: Yes.

Ben: Sure.
