# Bridge to Delivery

This folder contains visual stimulus cards for the **Integrator** persona.

The Integrator bridges design to delivery, asks build questions before the build phase begins, and refuses to let great ideas die in handoff.

## What to Add

Drop one or more images (.jpg, .jpeg, .png, .webp) into this folder. When the Integrator fires an intervention, the first image will be displayed as a visual reference.

Suggested imagery:
- Design-to-development handoff or bridge imagery
- Architecture or systems thinking
- Engineering or build phase scenes
- Execution or delivery moments
- Collaboration between teams
- Platform or infrastructure visuals
- Pragmatic or practical approaches
- Ambitious execution or shipping moments
- Building or construction metaphors

Maximum display height: 250px (auto-scaled to fit card width).
