# Find Unexpected Examples

This folder contains visual stimulus cards for the **Benchmarker** persona.

The Benchmarker brings outside-in patterns, evidence, and surprising precedents from other industries and contexts.

## What to Add

Drop one or more images (.jpg, .jpeg, .png, .webp) into this folder. When the Benchmarker fires an intervention, the first image will be displayed as a visual reference.

Suggested imagery:
- Cross-industry examples or analogies
- Benchmark or comparative data
- Different approaches or alternative models
- Evidence-based or data-driven visuals
- Outside perspective or external view
- Competitive landscape or market context
- Case study or real-world example scenes

Maximum display height: 250px (auto-scaled to fit card width).
