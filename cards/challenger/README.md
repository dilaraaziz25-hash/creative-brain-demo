# Challenge Assumptions

This folder contains visual stimulus cards for the **Challenger** persona.

The Challenger breaks convergence on safe answers, attacks obvious ideas, and demands more radical versions.

## What to Add

Drop one or more images (.jpg, .jpeg, .png, .webp) into this folder. When the Challenger fires an intervention, the first image will be displayed as a visual reference.

Suggested imagery:
- Disruption or bold moves
- Breaking rules or unconventional paths
- Contrarian thinking visuals
- Confrontation or debate scenes
- Radical innovation or transformation
- Red team or adversarial framing

Maximum display height: 250px (auto-scaled to fit card width).
