# Run a Quick Experiment

This folder contains visual stimulus cards for the **Experimenter** persona.

The Experimenter brings lateral energy and turns ideas into things the team can actually run today—small prototypes, quick tests, 24-hour gestures.

## What to Add

Drop one or more images (.jpg, .jpeg, .png, .webp) into this folder. When the Experimenter fires an intervention, the first image will be displayed as a visual reference.

Suggested imagery:
- Rapid prototyping or MVP scenes
- Action-oriented or hands-on work
- Playful or experimental mindset
- Quick iteration or agile sprints
- Small-scale testing or pilot projects
- Energy and momentum visuals
- Playful failure or learning moments
- 24-hour or rapid delivery imagery

Maximum display height: 250px (auto-scaled to fit card width).
